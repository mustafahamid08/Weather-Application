🌦️ Weather Application

A simple Python-based Weather Application that provides weather information for a selected location.

✨ Features

- Search weather by location
- Display current weather information
- Show temperature and weather conditions
- Simple and user-friendly interface
- Real-time weather data

🛠️ Technologies Used

- Python
- Weather API
- Requests

📌 Project Purpose

This project was created to practice Python concepts such as API integration, HTTP requests, JSON data handling, functions, user input, and error handling.
